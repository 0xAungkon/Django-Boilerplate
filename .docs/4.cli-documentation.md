# Example CLI Commands:
```
easyssh auth login              # Opens browser for SSO/email approval
easyssh auth status             # Shows current authentication state
easyssh auth logout             # Logs out current session

easyssh vaults                  # List all vaults
easyssh vault rename <id> <new> # Rename vault

easyssh ls                      # List all items in default vault
easyssh ls --vault <vault-id>   # List items from specific vault

easyssh add -u root -h host -p 22 ***(extra ssh params) # Add new SSH config

easyssh sync    # Upload ~/.ssh configs + keys to vault

easyssh connect <hostname/ip/alias>   # Connect using default vault
easyssh connect <hostname/ip/alias> --vault <vault-id> # Connect using another vault

easyssh config set url http://localhost:8000 # Change backend API URL
easyssh config add path ~/.ssh/config # Add extra config path for sync

easyssh help                    # List commands
easyssh help <command>          # Show help for a command
```

## Token Location
Linux / macOS → ~/.config/.easyssh/config.json
Windows → %APPDATA%\easyssh\config.json (or fallback to ~/.easyssh/config.json)
